# Componentes reutilizables: CSS Modules y Tailwind CSS

Ejercicio 1 del laboratorio de la semana 11. Combina CSS Modules (efectos complejos) con Tailwind CSS (estructura, colores y tamaños).

| Componente | Archivos |
|---|---|
| Button | `src/components/ui/Button.tsx`, `Button.module.css` |
| Card | `src/components/cards/Card.tsx` |
| Badge | `src/components/ui/Badge.tsx` |
| Input | `src/components/ui/Input.tsx`, `Input.module.css` |
| Página | `src/app/styling/page.tsx` |

## Ejecutar
```bash
npm install
npm run dev        # http://localhost:3000/styling
npm run build
npm start
```
